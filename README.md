# 地球OL - 人生RPG 成长追踪

把人生成长游戏化：每天记录成长、积累经验值、升级 6 维属性、解锁成就。
纯本地应用，数据只存在你自己的设备上。

## 快速开始

### 方式一：本地预览（电脑）

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 注意：必须通过 http 服务访问（不能直接双击打开 index.html），否则 PWA 功能不可用。

### 方式二：安装为手机 App（PWA，推荐）

PWA 安装后从主屏幕打开，是全屏独立窗口，体验接近原生 App。

1. 把整个文件夹部署到任意静态托管（GitHub Pages、CloudStudio、服务器等均可），拿到一个网址
2. 手机浏览器打开该网址
3. 添加到主屏幕：
   - Android Chrome：菜单 → 「添加到主屏幕」
   - iPhone Safari：分享 → 「添加到主屏幕」
4. 从主屏幕图标打开，即可像 App 一样使用

## 数据说明

- 数据存 localStorage，完全本地，不上传任何服务器
- 卸载 PWA 前建议先「设置 → 导出数据」备份；换设备用「导入数据」恢复
- 更新版本：重新部署后，重新打开 App 即自动获取新版本（Service Worker 网络优先策略）

## 功能

- 🎮 角色面板：等级、XP、连续天数
- 📊 6 维属性：智力/学习、情商/人际、健康/体能、财富/事业、意志力/自律、精神/心灵
- 🎯 雷达图 + 进度条可视化
- ✏️ 每日记录：选维度、难度、心情，自动计算 XP，10% 暴击
- 📊 定期自评：6 维度滑块打分，对比上次评估
- 📜 成长历程：按维度筛选历史
- 🏆 12 个成就系统
- ⚙️ 数据导入/导出

## 技术说明

- 纯静态单文件应用：`index.html` 内嵌全部 HTML/CSS/JS，零构建、零依赖、零后端
- PWA 离线缓存：`sw.js` 负责——页面请求网络优先（部署后自动更新），静态资源缓存优先（离线可用）
- 版本升级：修改 `sw.js` 顶部 `CACHE_NAME`（如 v2 → v3）可强制已安装用户换新缓存

## 项目结构

```
earth-online/
├── index.html      # 应用本体（全部逻辑）
├── sw.js           # Service Worker（离线缓存）
├── manifest.json   # PWA 清单
├── icon-192.png    # 应用图标
└── icon-512.png    # 应用图标（高清）
```
